# 🗄️ Armazenamento e Gestão de Dados (AGD)

Este repositório contém todo o conteúdo prático, scripts e exercícios desenvolvidos durante a disciplina de **Armazenamento e Gestão de Dados**. O objetivo principal destes materiais é documentar o aprofundamento dos conhecimentos em bancos de dados relacionais e a evolução das habilidades de escrita e estruturação de queries.

Todas as práticas, modelagens e testes de scripts presentes aqui foram desenvolvidos utilizando o **MySQL Workbench**.

## 📚 Tópicos Abordados

Durante a progressão da disciplina, os estudos passaram por conceitos que vão desde a criação estrutural até a automação de regras de negócio diretamente no banco, incluindo:

*   **DDL (Data Definition Language):** Criação, alteração e exclusão de estruturas de dados.
*   **DML (Data Manipulation Language):** Manipulação direta das informações através de inserções, atualizações e deleções.
*   **DQL (Data Query Language):** Construção de consultas, desde buscas simples até junções complexas (JOINs), agrupamentos e filtros.
*   **Views:** Criação de tabelas virtuais para encapsular lógicas de consultas recorrentes, visando segurança e organização.
*   **Stored Procedures:** Desenvolvimento de rotinas armazenadas no banco para automatizar processos e regras de negócio de forma eficiente.
*   **Functions:** Criação de funções personalizadas para realizar cálculos e tratamentos específicos de dados.
*   **Triggers:** Implementação de gatilhos para a execução automática de validações e auditorias baseadas em eventos nas tabelas.

## 🛠️ Tecnologias e Ferramentas Utilizadas

*   **Linguagem:** SQL
*   **SGBD / Ambiente:** MySQL Workbench

## 🎯 Resultados e Aprendizados

Este repositório consolida a melhoria contínua na habilidade de lidar com dados estruturados. A aplicação prática dos conceitos permitiu entender não apenas como armazenar informações, mas como extraí-las com eficiência e garantir a integridade dos dados através de programações internas (Procedures, Functions e Triggers), resultando em uma base sólida para a gestão e administração de bancos de dados.
